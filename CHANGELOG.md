# Changelog

All notable changes to **Bubble Catcher** are documented here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [Unreleased]

### Added

- Vue 3 frontend implementation with bubblemorphism design system
- Self-hosted authentication with JWT and refresh token rotation
- Biome linter and formatter integration with Justfile automation
- Automated CI and Release workflows in GitHub Actions

---

## [2.0.0] — 2026-03-01

### Added

- Self-hosted PostgreSQL schema with Drizzle ORM and trigger migrations
- Docker sandbox execution for PostgreSQL, MySQL, MariaDB, SQLite, and MSSQL
- Comprehensive SQL static analysis rule engine with 17 rules
- Native Bun test suite across backend and frontend

---

## [1.0.0] — 2026-02-12

### Added

- Initial stable release of Bubble Catcher
- Sandbox execution and heuristic query guard
- Analysis rule engine with 11 rules and multi-dialect support
- Saved query storage and internationalization (English & Spanish)
